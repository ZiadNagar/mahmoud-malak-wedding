# Groom & Bride Wedding Invitation Website

A beautifully crafted, responsive, and animated wedding invitation website for Groom and Bride. This project features a tailored design system, lush parallax effects, and buttery-smooth scrolling to provide a premium digital experience for their guests.

## ✨ Features

- **Immersive Parallax Hero:** Stunning depth-of-field effects on the landing view.
- **Premium Smooth Scrolling:** Powered by Lenis for fluid, momentum-based scrolling.
- **Entrance Animations:** Graceful reveal animations across all sections (Our Story, Gallery, Venue) using Framer Motion.
- **Custom Design System:** Tailored color palette (Primary, Secondary, Tertiary) with bespoke botanical SVG graphics.
- **Fully Responsive:** Optimized for a seamless experience on both mobile devices and large desktop screens.

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Motion (Framer Motion)](https://motion.dev/)
- **Scroll Physics:** [Lenis](https://lenis.studiofreight.com/)

## 🎨 Project Structure

- `src/components/` - Contains all modular UI sections (`Hero.tsx`, `Story.tsx`, `Gallery.tsx`, `Venue.tsx`, etc.)
- `src/index.css` - Global styles, Tailwind directives, and CSS variables for the color system.
- `src/App.tsx` - Root component initializing the Lenis smooth scroller and assembling the sections.
- `public/` - Static assets including images and the custom ring favicon.
